### 第二期排版

本目录制作《骋风逐曜》的[第二期来源稿](<../../第二期/目录.md>)。安装与稿件写法见[通用说明](<../README.md#运行>)。

```bash
cd 排版/第二期
python3 build.py 第二期
```

#### 本期处理

- 扉页与封面在[封面制作](<../封面/README.md>)阶段一起生成，后来才加入内页。运行前需备好 `排版/封面/第二期扉页.pdf`，`finalize()` 将它拼入首页。
- 人员表占扉页背面，其后为目录和空白页。这四页不计刊面页，正文第 1 页落在右页。
- 左页页眉为期名，右页页眉为板块名；卷尾语在全刊最后。

#### 输出

程序在 `排版/历史输出/第二期/` 保存 `第二期.html`、两份页码字形不同的内页 PDF、`第二期版面.json` 与 `images/` 缓存，并回填稿件目录。制作阶段归档 PDF 仍使用早期扉页；重建时使用本次封面程序生成的扉页。
