# 第二期排版

本目录是《骋风逐曜》编辑部方案的制作入口。先完成[共通依赖安装](<../README.md#生成>)；稿件写法与配图规则也见上一级说明。

```bash
cd 排版/第二期
npm install
npx playwright install chromium
python3 build.py 第二期
```

可用 `CHROMIUM_EXECUTABLE` 指定本机 Chromium。

## 本期处理

- `build.py` 读取[第二期来源稿](<../../第二期/目录.md>)，并使用上一级 `fonts/` 中的字体。
- `finalize()` 在内页前拼入 `资产/第二期扉页.pdf`；人员表占扉页背面，其后为目录和空白页。这四页不计刊面页，正文第 1 页落在右页。
- 左页页眉为期名，右页页眉为板块名；卷尾语在全刊最后。

## 历史输出

| 文件 | 说明 |
| --- | --- |
| `第二期.html` | 制作阶段生成的 HTML；字体路径随目录移动调整。 |
| `第二期内页.pdf` | 当时的内页输出，使用早期扉页。 |
| `第二期内页（齐线数字）.pdf` | 同一版面，页码改用齐线数字。 |
| `第二期版面.json` | 各篇起止页、留白与配图行数。 |
| `images/第二期/` | 当时生成的配图缓存。 |

现有封面、扉页资产采用发布的《骋风逐曜》设计；正式成品入口见[第二期目录](<../../第二期/目录.md>)。
