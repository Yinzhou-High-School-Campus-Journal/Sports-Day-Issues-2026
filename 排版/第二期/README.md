# 第二期排版

本目录制作《骋风逐曜》的编辑部版内页，稿件见[第二期目录](<../../第二期/目录.md>)，安装与运行见[排版说明](<../README.md#运行>)。

单独制作本期（须先生成 `排版/封面/第二期扉页.pdf`）：

```bash
python 第二期/build.py
```

版式沿用[第一期](<../第一期/README.md#版式>)，以下是本期的不同之处：

- 内页开头依次为扉页（右页）、人员表（扉页背面）、目录和空白页，这四页不计页数，正文第 1 页落在右页。Chromium 只排人员表以后的部分，扉页和空白页在拼页时补上。
- 左页页眉为期名，右页页眉为板块名；板块起始页没有配图时，内容上下居中。
- 目录标出班级；卷尾语排在全刊最后，在目录中列于各板块之后。
