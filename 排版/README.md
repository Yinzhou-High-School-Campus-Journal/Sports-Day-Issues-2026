# 排版

《云图试骏》内页用 HTML 排版、Chromium 打印成 PDF。封面和扉页另做（见 `资产/`），不在这里生成。

本分支排的是第二期。第一期未付印的五板块版本和它的排版结果保留在 `ShenZehou` 分支。

| 文件 | 说明 |
| --- | --- |

| `style.css` | 版式样式 |
| `第二期内页.pdf` | 印刷用内页（从目录起） |

## 版式

- A4，页边距上 24.5 mm、下 27.5 mm、内外侧 27.2 mm；版心恰好是双栏各 20 字 × 40 行。
- 正文：思源宋体 Regular + Noto Serif 350，10.5 pt，行距 17.35 pt，首行缩进 21 pt，双栏，栏间距 21 pt，两端对齐。
- 西文：正文里夹排的数字、短西文用 Noto Serif（字重与宋体相近）；成段西文和独立西文（页码、目录页码、班级号）用 Constantia。页码用 Constantia 的旧式数字。
- 裸大标题（目录、板块起始页）：思源宋体 Bold 18 pt，行距 26.04 pt，段后 3.5 行。
- 大标题：思源宋体 Bold 18 pt，行距 26.04 pt，上方补半行，让标题区占满整行。副标题 12 pt，紧跟大标题。
- 作者：方正恒仿宋 Medium 10.5 pt，行距 17.35 pt，段前段后 2.5 行。
- 中标题：思源宋体 SemiBold 14 pt，行距 17.35 pt，段前段后 1 行，居中。
- 小标题：思源宋体 Medium 12 pt，行距 17.35 pt，段前段后 0.5 行，左齐。
- 目录：两栏，每条为「题目　班级号　姓名　页码」。班级号用 Constantia 齐线数字，单占一格；姓名栏至少三字宽，两字名两端撑开，班级号、姓名上下对齐。长题目只在逗号、空格处转行。
- 板块名：红砖絮语、赛道秋声、青衿问道、古韵新声（四字，不与第一期重复；在 `ISSUES` 的 `section_names` 里配置，稿件目录名沿用 `print` 分支）。
- 人员表单独一页，印在扉页背面：仿 V5 竖式，窄窄一栏，每行至多两个姓名，转行与首个姓名对齐；职务按最长的撑成同宽，冒号、姓名上下对齐；方正恒仿宋，整块在版心里上下左右居中，不印页码。
- 板块起始页：板块名、导读（方正恒仿宋，单栏通排）和一幅大图，整组内容上下居中（上方补的空白取整行）；没有贴题的图时不配图，导读写长。这一期不设卷首语、致辞。
- 页码从目录之后起算：目录页不印页码、不计页数，目录后的第一页为第 1 页，目录里的页码同此。PDF 的页码标签与之一致，前置页（封面、扉页、人员表、目录）标罗马数字。
- 诗：整篇是诗时单栏居中；诗行短、诗节多的（如《青春颂》）排双栏，诗节之间可换栏。
- 篇首题记（「引文」——出处）：方正恒仿宋，左缩两字，出处右齐。
- 标点挤压：`text-spacing-trim: trim-start`（行首开口标点和相邻标点挤压）；样式里同时写了 `trim-both`，浏览器支持后行尾也会压缩（Chromium 141 尚不支持）。
- 中西文自动加空：`text-autospace: normal`。稿件里不要手打中西文之间的空格。
- 段末孤字：`text-wrap: pretty`，避免段落最后一行只剩一个字。
- 每篇另起一页；页眉为板块名（由 `build.py` 按期刊配置生成），页脚为页码；目录和板块起始页不设页眉。

## 网格

- 所有正文行落在同一套 17.35 pt 行线上，左右两栏逐行对齐；标题区、中标题、小标题、引文、诗行都占整数行。
- 插图占整数行，图片本身上下内缩到汉字字面框（行框内 3.51–14.01 pt），与旁栏、上下文字的字身齐平。
- 行内换用别的字体（班级号、斜体、Constantia 歌词）时 `line-height: 1`，不撑高行框。
- 只要有一个元素横向超出版心，Chromium 打印时就会把整份文档等比缩小去适应页宽，所有行距都偏离网格。`render.cjs` 打印前会检查并列出超出的元素。
- Chromium 141 的标点挤压有个毛病：行尾「。」」这类连续标点，断行时按行尾引号可以压半宽计算，画的时候却不压，字会伸出栏外半个字。`render.cjs` 发现哪一段有字伸出栏外，就只对这一段关掉标点挤压（第二期只有《寻乡》一段）。

## 稿件写法

```markdown
# 标题

2503 作者姓名

——副标题（可选）

---

「篇首题记（可选）」——出处

正文段落……西文书名用 *斜体*，不加书名号。

### 一、中标题

> 引文或歌词，每行末尾两个空格  
> ——出处, *Title*

诗行，每行末尾两个空格  
下一行

![说明](../../资产/图片.jpeg)
```

- 板块目录可以带序号前缀（`01_赴新征`），稿件文件名用两位数字前缀排序；页眉和目录里去掉前缀。
- 文中出现的第一级 `#` 标题排成中标题，第二级排成小标题。
- 文末连着两张以上的图，排成通栏并排的图组。
- 引号用「」，嵌套用『』；破折号 `——`、省略号 `……`。
- 各板块目录下的 `00_导读.md` 是板块起始页的导读。
- `00_前置/01_人员表.md` 每行「职务：姓名　姓名」，姓名之间用全角空格；排成扉页背面的人员表页。

## 配图

`build.py` 里每期一份配置（`ISSUES`、`FILLS_2`）。`art` 为 `art.py` 的图样名，`photo` 为照片。第一遍排版后量出每篇末页还空几行，插图高度按剩余行数自动取整；`where: "head"` 的图放在作者行下方，用于把只溢出几行的文章撑成匀称的两页。

照片一律转灰度（自动色阶、提亮中间调抵消网点扩大）。视频截图按原比例取高（`max`），多出的行留在图上方、图沉到页底（`anchor: "bottom"`），不硬裁成方图。同一类画面全书尽量只出现一次。

## 生成

需要 Python 3（`pip install pymupdf pillow fonttools`）和 Node.js。

```bash
cd 排版
npm install                      # 安装 Playwright
npx playwright install chromium  # 首次使用时下载 Chromium
python3 fonts.py                 # 字体已收录；缺失时下载并生成静态字重
python3 build.py 第二期
```

没有 Playwright 自带的浏览器时，可用环境变量 `CHROMIUM_EXECUTABLE` 指定本机的 Chrome / Chromium。

所需字体均已收录在 [`fonts/`](fonts/README.md)：方正恒仿宋 `FZHengFSJF-R.TTF`、`FZHengFSJF-M.TTF`，Constantia `CONSTAN.TTF`、`CONSTANB.TTF`、`CONSTANI.TTF`、`CONSTANZ.TTF`，以及思源宋体字形和 Noto Serif 的可变字体与静态字重。开源字体的许可文本随目录提供；商业字体按项目维护者确认的再分发授权收录。
