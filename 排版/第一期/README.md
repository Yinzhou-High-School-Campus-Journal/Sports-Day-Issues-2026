### 第一期排版

本目录制作《云图试骏》的[第一期来源稿](<../../第一期/目录.md>)。安装与稿件写法见[通用说明](<../README.md#运行>)。

```bash
cd 排版/第一期
python3 build.py 第一期
```

#### 输出与扉页

程序输出到 `排版/历史输出/第一期/`：`第一期.html`、`第一期内页.pdf`、`第一期版面.json`、`第一期（含封面预览）.pdf` 以及 `images/` 缓存。

制作阶段的内页为 52 页，不含扉页；扉页后来与封面一起制作，再拼入发布的内页，因此编辑部 Release 文件为 53 页。封面预览则按封面、扉页、52 页内页组合。此处保留原制作流程，未把后来拼入的扉页改成内页源码生成的内容。

#### 版式

- A4，页边距上 24.5 mm、下 27.5 mm、内外侧 27.2 mm；版心恰好是双栏各 20 字 × 40 行。
- 正文：思源宋体 Regular + Noto Serif 350，10.5 pt，行距 17.35 pt，首行缩进 21 pt，双栏，栏间距 21 pt，两端对齐。
- 西文：正文里夹排的数字、短西文用 Noto Serif（字重与宋体相近）；成段西文（歌词）和独立西文（页码、目录页码、班级号）用 Constantia。页码用 Constantia 的旧式数字。
- 裸大标题（卷首语、致辞、目录、板块起始页）：思源宋体 Bold 18 pt，行距 26.04 pt，段后 3.5 行。
- 大标题：思源宋体 Bold 18 pt，行距 26.04 pt，上方补半行，让标题区占满整行。副标题 12 pt，紧跟大标题。
- 作者：方正恒仿宋 Medium 10.5 pt，行距 17.35 pt，段前段后 2.5 行。
- 中标题：思源宋体 SemiBold 14 pt，行距 17.35 pt，段前段后 1 行，居中。
- 小标题：思源宋体 Medium 12 pt，行距 17.35 pt，段前段后 0.5 行，左齐。
- 卷首语、开幕式致辞、板块导读单栏通排（每行 42 字）；导读用方正恒仿宋。
- 人员表排在卷首语页底：一道细线，下面两栏与正文栏对齐，方正恒仿宋 10.5 pt，行距同正文；姓名转行时与首个姓名对齐。
- 标点挤压：`text-spacing-trim: trim-start`（行首开口标点和相邻标点挤压）；样式里同时写了 `trim-both`，浏览器支持后行尾也会压缩（Chromium 141 尚不支持）。
- 中西文自动加空：`text-autospace: normal`。稿件里不要手打中西文之间的空格。
- 段末孤字：`text-wrap: pretty`，避免段落最后一行只剩一个字。
- 每篇另起一页；页眉为板块名，页脚为页码（内页第 1 页起算）；板块起始页和卷首语、目录不设页眉。

#### 网格

- 所有正文行落在同一套 17.35 pt 行线上，左右两栏逐行对齐；标题区、中标题、小标题、引文、诗行都占整数行。
- 插图占整数行，图片本身上下内缩到汉字字面框（行框内 3.51–14.01 pt），与旁栏、上下文字的字身齐平。
- 行内换用别的字体（班级号、斜体、Constantia 歌词）时 `line-height: 1`，不撑高行框。
