# 封面与扉页

两期的封面和扉页用同一套程序制作；扉页另做成单页 PDF，由内页程序拼入。

| 文件 | 用途 |
| --- | --- |
| `make_pages.py` | 第一期《云图试骏》封面与扉页的 HTML。 |
| `make_issue2.py` | 第二期《骋风逐曜》封面与扉页的 HTML。 |
| `render.cjs` | 用共用的浏览器输出 PDF 和 PNG，资源载入失败即报错。 |
| `build.py` | 依次生成两期的封面与扉页，全部成功后才替换旧文件。 |

单独制作（`python release.py` 已包含这一步）：

```bash
python 封面/build.py
```

输出在本目录：两期的封面、扉页各一份 PDF 与 PNG。字体全部取自[共享字体目录](<../fonts/README.md>)。封面用的思源宋体是只含原封面字形的子集：改了封面文字而子集缺字时，Chromium 会改用本机字体，构建时查出就报错，这时须从思源宋体重新取出包含新增字的子集。
