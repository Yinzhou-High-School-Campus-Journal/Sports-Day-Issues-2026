### 概览

欢迎来到《校园运动会特别刊物》2026 年版的 GitHub 仓库。此版本与先前一样，分为两期，第一期为《云图试骏》，第二期《骋风逐曜》。注意，此仓库未经媒体部授权，为《鄞年・思叙》编辑部自行上传。因此，我们只能把技术范围内能上传／归档的所有文件都上传到此处。

### 为什么要建立此仓库？

自 2026 学年的学生会媒体部招新以来，媒体部一直面临着技术人手／水平不足的境况。因此，《鄞年・思叙》编辑部与主管媒体部的学生会副主席杨上喆一拍即合，决定让校刊编辑部参与《校园运动会特别刊物》的编辑工作。为了使下次潜在合作更为顺利，也为了将我们的幕后工作流程（如未刊发的稿件）展现给各位，特此建立该仓库。

### 为什么本仓库有三个分支？

因为协调混乱的缘故，实际上参与校刊编辑制作的有四方：

- 学校
   - 代表人物：李锦涛
   - 主要负责：
      - 划定大框架
      - 决定小部分稿件编排
- 学生会媒体部
   - 代表人物：杨上喆
   - 主要负责：
      - 初步审稿
      - 封面制作
      - 稿件编排
- 《鄞年・思叙》编辑部
   - 代表人物：沈泽厚
   - 主要负责：排版
- 上期《校园运动会特别刊物》执行编辑
   - 代表人物：段嘉瑞
   - 主要负责：排版

因此，三个分支代表的是本刊的三种不同走向：

- `DuanJiarui` 分支
   - 完全按上期《校园运动会特别刊物》执行编辑设想进行的情况
      - 《云图试骏》除封面外完全由他们制作，《鄞年・思叙》编辑部仅进行了查找错别字等方面的协助
      - 未参与《骋风逐曜》的制作
- `ShenZehou` 分支
   - 完全按《鄞年・思叙》编辑部设想进行的情况
      - 编辑部在《云图试骏》上提供的方案不幸落选
      - 但由于 AI 的速度与质量优势，成功进行了《骋风逐曜》的制作
- `Print` 分支
   - 校方最终印刷的情况
      - 因校方与上期执行编辑共同在机房交流制作，双方改动的贡献无法区分，本分支的《云图试骏》与 `DuanJiarui` 分支一致
      - 因编辑部的 AI 的 Session 配额耗尽与时间限制，校方又在编辑部提交最终版本后继续使用了某 PDF 编辑器（WPS？）进行了编辑

### 本分支说明

校运会特刊第一期名「云图试骏」，第二期名「骋风逐曜」。本分支采用《2026校刊运动会特辑·1 V5.pdf》的第一期编排。V5 是唯一的第一期成品，PDF 保存在仓库外；本分支保存两期的稿件、校对记录和第二期的排版（`排版/`）。

`第一期/`（本期名「云图试骏」）按 V5 阅读顺序命名：`00_前置`（人员表、开幕式致辞、卷首语），然后依次为 `01_赴新征`（7 篇）、`02_奋云程`（6 篇）、`03_笃前行`（4 篇）、`04_逐韶光`（7 篇）。各板块内的稿件编号也是 V5 顺序。

`第二期/`（本期名「骋风逐曜」）保存当前入选的 39 篇稿件，实质板块按 V5 顺序排列：`01_赴新征`（9 篇）、`02_竞风华`（9 篇，运动会板块）、`03_笃前行`（8 篇）、`04_逐韶光`（13 篇），印出来的板块名依次为红砖絮语、赛道秋声、青衿问道、思接千载。各板块目录的 `00_导读.md` 是板块起始页的导读；`人员表.md` 排在扉页背面、目录之前，`卷尾语.md` 排在全刊最后。板块内文件以两位数字前缀排序，`目录.md` 提供链接和页码（由排版脚本生成）；正文合计约 3.5 万汉字。第二期的排版在 [`排版/`](排版/README.md)，扉页取自 `资产/第二期扉页.pdf`，尚未付印。

未进入两期的稿件收在 `待选稿/`，不带旧方案的排序号；作者或班级仍未知的稿件保留在 `信息缺失/`。本分支的稿件正文分节小标题统一使用「一」或「一、标题」这样的中文数字格式。`ShenZehou` 分支另保留未付印的原五板块第一期与对应排版。

V5 PDF 仍需排版端回改的项目保存在 `DuanJiarui` 分支的 [V5 校样更正](https://github.com/Yinzhou-High-School-Campus-Journal/Sports-Day-Issues-2026/blob/DuanJiarui/V5校样更正.md)。
