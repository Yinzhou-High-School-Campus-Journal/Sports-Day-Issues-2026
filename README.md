# 校运会校刊 print 分支

本分支采用《2026校刊运动会特辑·1 V5.pdf》的第一期编排。V5 是唯一的第一期成品，PDF 保存在仓库外；本分支保存稿件和校对记录，不保存排版目录或旧版封面。

`第一期/` 按 V5 阅读顺序命名：`00_前置`（人员表、开幕式致辞、卷首语），然后依次为 `01_赴新征`（7 篇）、`02_奋云程`（6 篇）、`03_笃前行`（4 篇）、`04_逐韶光`（7 篇）。各板块内的稿件编号也是 V5 顺序。

`第二期/` 保存当前入选的 39 篇稿件，实质板块按 V5 顺序排列：`01_赴新征`（10 篇）、`02_竞风华`（8 篇，运动会板块）、`03_笃前行`（8 篇）、`04_逐韶光`（13 篇）。板块内文件以两位数字前缀排序，`目录.md` 提供链接；正文合计约 3.5 万汉字。第二期尚未排版付印。

未进入两期的稿件收在 `待选稿/`，不带旧方案的排序号；作者或班级仍未知的稿件保留在 `信息缺失/`。本分支的稿件正文分节小标题统一使用「一」或「一、标题」这样的中文数字格式。`ShenZehou` 分支另保留未付印的原五板块第一期与对应排版。

V5 PDF 仍需排版端回改的项目保存在 `DuanJiarui` 分支的 [V5 校样更正](https://github.com/Yinzhou-High-School-Campus-Journal/Sports-Day-Issues-2026/blob/DuanJiarui/V5校样更正.md)。
