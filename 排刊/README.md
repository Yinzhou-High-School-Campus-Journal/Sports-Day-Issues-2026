## 编排说明

- 第一期开篇以校运会筹备、长绳、接力、看台与跑道经历为主。《凌汐》列入本期少年心语。
- 原 50 篇排序中的第 11、12、13 篇《时间，我祈求你开得慢些》《寻乡》《花念春》依次转入第二期少年心语。
- 双栏试排时，《银球有光》《渡》《十八而立》《鄞园琐记》《泰晤士畔，一千次》《浙里皮影流年》在第二页只余少量文字，因此暂不进入两期排刊目录。
- 《变声期》作为较长叙事排入第二期。《寻猫记》与第二期其他待复核稿在锁定目录前还需完成相应的篇幅和内容审核。
