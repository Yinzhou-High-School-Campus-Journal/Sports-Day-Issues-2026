# 排版

《云图试骏》内页用 HTML 排版、Chromium 打印成 PDF。封面和扉页另做（见 `资产/`），不在这里生成。

## 文件

| 文件 | 说明 |
| --- | --- |
| `第一期.html` | 排版源文件（由 `build.py` 从稿件生成，可直接用 Chrome 打开或打印） |
| `style.css` | 版式样式 |
| `第一期内页.pdf` | 印刷用内页 |
| `第一期（含封面预览）.pdf` | 封面 + 扉页 + 内页，仅供翻阅 |
| `第一期版面.json` | 每篇的起止页、末页留白行数、配图行数 |
| `build.py` | 稿件 → HTML → PDF：回填目录页码，量出留白后按配置放插图 |
| `art.py` | 线描插图生成器（沿用封面画风，按版面尺寸出 SVG） |
| `render.cjs` | 调用 Chromium 输出 PDF |
| `fonts.py` | 准备字体（输出到 `fonts/`，不进仓库） |
| `images/` | 灰度处理后的照片（`fill/` 为留白配图）和生成的线描（`art/`） |

## 版式

- A4，页边距上 24.5 mm、下 27.5 mm、内外侧 27.2 mm；版心恰好是双栏各 20 字 × 40 行。
- 正文：思源宋体 Regular + Noto Serif 350，10.5 pt，行距 17.35 pt，首行缩进 21 pt，双栏，栏间距 21 pt，两端对齐。
- 西文：正文里夹排的数字、短西文用 Noto Serif（字重与宋体相近）；成段西文（歌词）和独立西文（页码、目录页码、班级号）用 Constantia。页码用 Constantia 的旧式数字。
- 裸大标题（卷首语、致辞、目录、板块起始页）：思源宋体 Bold 18 pt，行距 26.04 pt，段后 3.5 行。
- 大标题：思源宋体 Bold 18 pt，行距 26.04 pt，上方补半行，让标题区占满整行。副标题 12 pt，紧跟大标题。
- 作者：方正恒仿宋 Medium 10.5 pt，行距 17.35 pt，段前段后 2.5 行。
- 中标题：思源宋体 SemiBold 14 pt，行距 17.35 pt，段前段后 1 行，居中。
- 小标题：思源宋体 Medium 12 pt，行距 17.35 pt，段前段后 0.5 行，左齐。
- 卷首语、开幕式致辞、板块导读单栏通排（每行 42 字）；导读用方正恒仿宋。
- 人员表排在卷首语页底：一道细线，下面两栏与正文栏对齐，方正恒仿宋 10.5 pt，行距同正文；姓名转行时与首个姓名对齐。
- 标点挤压：`text-spacing-trim: trim-start`（行首开口标点和相邻标点挤压）；样式里同时写了 `trim-both`，浏览器支持后行尾也会压缩（Chromium 141 尚不支持）。
- 中西文自动加空：`text-autospace: normal`。稿件里不要手打中西文之间的空格。
- 段末孤字：`text-wrap: pretty`，避免段落最后一行只剩一个字。
- 每篇另起一页；页眉为板块名，页脚为页码（内页第 1 页起算）；板块起始页和卷首语、目录不设页眉。

## 网格

- 所有正文行落在同一套 17.35 pt 行线上，左右两栏逐行对齐；标题区、中标题、小标题、引文、诗行都占整数行。
- 插图占整数行，图片本身上下内缩到汉字字面框（行框内 3.51–14.01 pt），与旁栏、上下文字的字身齐平。
- 行内换用别的字体（班级号、斜体、Constantia 歌词）时 `line-height: 1`，不撑高行框。

## 稿件写法

```markdown
# 标题

2503 作者姓名

——副标题（可选）

---

正文段落……西文书名用 *斜体*，不加书名号。

### 中标题

> 引文或歌词，每行末尾两个空格  
> ——出处, *Title*

诗行，每行末尾两个空格  
下一行

![说明](../../资产/图片.jpeg)
```

- 文中出现的第一级 `#` 标题排成中标题，第二级排成小标题。
- 整篇都是诗行时，单栏居中排。
- 文末连着两张以上的图，排成通栏并排的图组。
- 引号用「」，嵌套用『』；破折号 `——`、省略号 `……`。
- 各板块目录下的 `0_导读.md` 是板块起始页的导读。
- `人员表.md` 每行「职务：姓名　姓名」，姓名之间用全角空格。

## 配图

`build.py` 里的 `FILLS` 按文章配置留白插图：`art` 为 `art.py` 的图样名（云海、银杏、折纸老虎、鼓楼、垂柳、墨勾山脊等，均按文章内容选），`photo` 为照片；钟楼、校园实景这类画不好的，一律用视频截图。第一遍排版后量出每篇末页还空几行，插图高度按剩余行数自动取整；`where: "head"` 的图放在作者行下方，用于把只溢出几行的文章撑成匀称的两页。

照片一律转灰度（自动色阶、提亮中间调抵消网点扩大）。视频截图按原比例取高（`max`），多出的行留在图上方、图沉到页底（`anchor: "bottom"`），不硬裁成方图。同一类画面（跑道、钟楼、群山、落日）全书尽量只出现一两次。

## 生成

需要 Python 3（`pip install pymupdf pillow fonttools`）和 Node.js。

```bash
cd 第一期/排版
npm install                      # 安装 Playwright
npx playwright install chromium  # 首次使用时下载 Chromium
python3 fonts.py                 # 下载并生成思源宋体、Noto Serif 静态字重
python3 build.py 第一期
```

商业字体需自行放进 `fonts/`：方正恒仿宋 `FZHengFSJF-R.TTF`、`FZHengFSJF-M.TTF`（缺少时退回开源的朱雀仿宋 `ZhuqueFangsong-Regular.ttf`），Constantia `CONSTAN.TTF`、`CONSTANB.TTF`、`CONSTANI.TTF`、`CONSTANZ.TTF`。
